# emoji-picker

Небольшой нативный выбиральщик emoji в стиле dmenu для Wayland (проверялся в расчёте на niri).
Запускаешь, печатаешь запрос, выбираешь emoji стрелками или мышью, жмёшь Enter — emoji скопирован в буфер обмена.

Написан на Rust с использованием GTK4. Список emoji и их названия берутся из крейта [`emojis`](https://crates.io/crates/emojis) и вшиваются в бинарник. Названия на других языках не вшиты: их можно скачать в настройках из [Unicode CLDR](https://github.com/unicode-org/cldr).

## Возможности

- поиск по английскому названию и shortcode (`:thumbs_up:`), а с применённой локализацией — ещё и по её названиям и ключевым словам (для русского: «лайк», «огонь», «программист»); несколько слов в запросе работают как «И», «ё» и «е» не различаются
- локализации названий скачиваются, применяются, снимаются и удаляются прямо в настройках; с применённой локализацией в списке показывается её название, под ним английское
- список недавно использованных emoji (можно отключить и ограничить по количеству)
- управление с клавиатуры и мыши
- открывается оверлеем поверх всех окон по центру экрана (через wlr-layer-shell, как dmenu/fuzzel) и забирает клавиатуру себе; закрывается по `Esc` или после выбора

## Управление

| Клавиши | Действие |
|---|---|
| печать текста | поиск |
| `↑` / `↓`, `Ctrl+P` / `Ctrl+N` | выбор emoji в списке |
| `Tab` | переключение фокуса список ⇄ поле ввода |
| `←` / `→` | в поле ввода — перемещение текстового курсора |
| `Enter` или клик | скопировать выбранный emoji и закрыть окно |
| `Ctrl+,` | открыть / закрыть настройки |
| `Esc` | закрыть окно (в настройках — вернуться назад) |

В режиме списка обычные символы и `Backspace` автоматически возвращают в поле ввода.

## Настройки

Открываются по `Ctrl+,` прямо в окне и применяются сразу:

- тёмная тема (вкл/выкл; при выключении остаётся то, что выбрано в системных настройках GTK)
- показывать недавние emoji (вкл/выкл)
- максимальное количество недавних (1–200, по умолчанию 24)
- локализации названий: список языков с кнопками «Скачать», «Применить», «Снять», «Удалить». Применена может быть одна локализация. Язык, которого нет в списке, можно скачать по коду CLDR (например `sr_Latn`) через поле внизу. Скачиваются файлы `common/annotations/<код>.xml` и `common/annotationsDerived/<код>.xml` из репозитория CLDR; нужен интернет и `curl`

Файлы:

- `~/.config/emoji-picker/config` — настройки (`recent_enabled`, `recent_max`, `locale`, `dark`)
- `~/.local/share/emoji-picker/recent` — список недавних, по одному emoji в строке
- `~/.local/share/emoji-picker/locales/<код>.tsv` — скачанные локализации: emoji, название, ключевые слова через `|`

## Структура

- `src/main.rs` — запуск приложения
- `src/ui.rs` — главное окно, список emoji, клавиатура, буфер обмена
- `src/settings.rs` — страница настроек, тёмная тема, управление локализациями
- `src/search.rs` — поиск и ранжирование
- `src/locale.rs` — скачивание и разбор локализаций CLDR
- `src/config.rs` — конфиг и список недавних

## Зависимости

Arch Linux:

```sh
sudo pacman -S --needed rust gtk4 gtk4-layer-shell wl-clipboard noto-fonts-emoji curl
```

- `rust` — компилятор и cargo (можно взять через rustup)
- `gtk4` — графическая библиотека
- `gtk4-layer-shell` — чтобы окно было оверлеем, а не обычным окном
- `wl-clipboard` — программа `wl-copy`, через которую emoji попадает в буфер обмена
- `noto-fonts-emoji` — шрифт с цветными emoji
- `curl` — для скачивания локализаций (обычно уже установлен)

Для сборки также нужен `pkgconf` и компилятор C (обычно уже есть в `base-devel`).

## Сборка

```sh
git clone <repo-url> emoji-picker   # или просто перейди в папку проекта
cd emoji-picker
cargo build --release
```

Готовый бинарник окажется в `target/release/emoji-picker`.

## Установка

```sh
install -Dm755 target/release/emoji-picker ~/.local/bin/emoji-picker
```

Убедись, что `~/.local/bin` есть в `$PATH`. Либо запусти без установки: `cargo run --release`.

## Настройка niri

Добавь в `~/.config/niri/config.kdl`:

```kdl
binds {
    Mod+Period { spawn "emoji-picker"; }
}
```

`window-rule` не нужен: приложение — не обычное окно, а layer-shell поверхность (namespace `emoji-picker`), её niri не кладёт в колонки. При желании её можно стилизовать через `layer-rule { match namespace="emoji-picker" ... }`.

## Возможные проблемы

- **emoji не копируется или копируется пустым** — проверь, что установлен `wl-clipboard` (`which wl-copy`). Без него приложение копирует через GTK, но содержимое пропадает после закрытия окна, если нет менеджера буфера обмена.
- **вместо emoji квадратики** — установи `noto-fonts-emoji` и перезапусти приложение.
- **открывается обычным окном, а не оверлеем** — значит, композитор не поддерживает wlr-layer-shell (niri поддерживает), и приложение откатилось на обычное окно. Пакет `gtk4-layer-shell` при этом нужен в любом случае: без него программа не соберётся и не запустится.
- **тёмная тема не включается** — переменная окружения `GTK_THEME` задаёт тему жёстко (например `GTK_THEME=Adwaita` без `:dark`), либо у темы нет тёмного варианта.
